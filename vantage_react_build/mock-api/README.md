# Vantage Learning Mock API

This folder contains the local Mock API used by the React frontend.

## Start

```powershell
cd mock-api
npm install
npm start
```

The API runs at:

http://localhost:5000

Useful endpoints:

- GET /users
- POST /users
- GET /users/:id
- PATCH /users/:id
- DELETE /users/:id
- GET /courses
- POST /courses
- GET /courses/:id
- PUT /courses/:id
- DELETE /courses/:id

The React frontend is configured to use `http://localhost:5000`.
